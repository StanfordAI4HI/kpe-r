# Resolve a propensity-model spec (used only when is_rct = FALSE). Returns a builder producing a list with \`fit(X, A, n_actions)\` and \`predict_proba(X)\`.

Resolve a propensity-model spec (used only when is_rct = FALSE). Returns
a builder producing a list with \`fit(X, A, n_actions)\` and
\`predict_proba(X)\`.

## Usage

``` r
.resolve_propensity_model(spec, seed = NULL)
```
