# Closed-form ridge: (X'X + lambda \* I)^-1 X'y with no penalty on intercept. X must already include a leading intercept column.

Closed-form ridge: (X'X + lambda \* I)^-1 X'y with no penalty on
intercept. X must already include a leading intercept column.

## Usage

``` r
.ridge_closed_form(X, y, lambda)
```
